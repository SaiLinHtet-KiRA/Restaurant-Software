Restaurant Table Order Management System — Designed and built a full-stack mobile POS application for restaurant table and order management, featuring a RESTful API backend built with Express 5, TypeScript, and MongoDB following a Controller-Service-Repository pattern, alongside a cross-platform mobile app using React Native (Expo SDK 54) with Redux Toolkit for order state management and RTK Query for API caching with automatic cache invalidation. Implemented Zod-powered runtime validation across all endpoints, auto-incrementing ID counters for tables, items, and orders, and cloud image storage for menu items via Vercel Blob with Multer uploads. The mobile app delivers a grid-based table selection interface, menu management with category-based item browsing and photo uploads, dual dine-in/takeaway order creation with real-time price calculation, active order editing and cash-out flow with payment method logging, transaction history with itemized receipt views, and responsive tablet/phone layouts via NativeWind (Tailwind CSS for React Native) and Expo Router file-based navigation with bottom tabs. Wrote comprehensive integration tests using Jest, Supertest, and mongodb-memory-server to ensure API reliability across all modules.
